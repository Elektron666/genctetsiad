# Tasarım prototipi — YAYINLANMAZ

Bu klasör, uygulamanın ilk tasarım denemesidir (tarayıcıda çalışan HTML
mockup). Tasarım geçmişi olarak saklanıyor; **ürünün parçası değildir.**

⛔ **Yayınlanmamalı.** İçinde tasarım amaçlı üretilmiş 34 sahte üye kaydı
var ve aralarında gerçek kişilerin adları geçiyor. `vercel.json` bir
dönem bu klasörü açık internete yayınlıyordu; artık `docs/` yayınlanıyor.

Ayrıca tarayıcıda Babel derleyen ve React'in *development* derlemesini
yükleyen bir sayfadır — hiçbir şekilde üretim için uygun değildir.

Gerçek uygulama: `native/`

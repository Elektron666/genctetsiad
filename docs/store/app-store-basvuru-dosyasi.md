## 9 · Bildirimler (isteğe bağlı, sonraya bırakılabilir)

iOS'ta Firebase/FCM **yetmez**; Apple Push Notification service (APNs)
anahtarı gerekir.

1. **developer.apple.com** → Certificates, Identifiers & Profiles → Keys
2. **+** → adı `Genç TETSİAD Push` → **Apple Push Notifications service (APNs)** işaretle → Continue → Register
3. `.p8` dosyasını indirin — **yalnızca bir kez indirilebilir**
4. Terminal: `eas credentials` → iOS → Push Notifications → dosyayı yükleyin

Bu adım atlanırsa uygulama sorunsuz çalışır, yalnızca bildirim gitmez.

```

     Platform : iOS
     Branch   : main

   → iPhone'unuza kurup BAŞTAN SONA deneyin
